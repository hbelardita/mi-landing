# Mi Landing Page

Este proyecto es una landing page básica desarrollada como parte de las prácticas del módulo de Git en el bootcamp de Devlights. Su propósito es servir como base para ejercitar el control de versiones, la gestión de ramas y las buenas prácticas en commits.

## Clonar el repositorio

```bash
git clone https://github.com/hbelardita/mi-landing.git
cd mi-landing
```

## Visualizar la página

Puedes abrir el archivo `index.html` directamente en tu navegador:

- **Desde la terminal:**

  ```bash
  # Linux
  xdg-open index.html

  # macOS
  open index.html

  # Windows (PowerShell / CMD)
  start index.html
  ```

- **O bien:** Haciendo doble clic sobre el archivo `index.html` desde el explorador de archivos, o utilizando extensiones como _Live Server_ en Visual Studio Code.
